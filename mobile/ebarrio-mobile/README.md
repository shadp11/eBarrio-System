# eBarrio Mobile App (Frontend)

## Overview

The eBarrio Mobile App helps residents with easy access to barangay services through their mobile devices. Users can receive community updates, access digital services, communicate with barangay officials, and use emergency and disaster management features, all within a single platform.

## Features

- Digital Document Services (request and access barangay documents)
- Real-Time Announcements & Notifications
- Real-Time Chat
- Emergency & Disaster Management Tools (SOS reporting, alerts, and information)

## Tech stack

- React Native
- Expo
- Axios
- Socket.IO client
- Firebase
- Expo Notifications

## Installation

Prerequisites:
Before running the application, make sure you have the following installed:

- Node.js
- npm or yarn
- Expo Go (mobile testing)
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/shadp11/eBarrio-System.git
cd eBarrio-System/mobile/ebarrio-mobile
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Expo App

```bash
npx expo start
```

### 4. Run the App

- Scan the QR Code using Expo Go Or press a to open the project in Android emulator

## Backend dependency

The mobile app requires the mobile backend service to be running separately. See `mobile/ebarrio-mobile-backend/README.md` for backend setup.

## Project structure

- `App.js` — entry point
- `components/` — screen components
- `context/` — React context providers
- `assets/` — images and fonts
